
# Digital Library & Reader

**Описание:** Приложение для управления личной коллекцией электронных книг и отслеживания прогресса чтения. Пользователь может каталогизировать книги, а также «открывать» их для чтения, при этом система автоматически сохраняет текущую страницу и обновляет статус прочтения.

**Основная сущность:** `Book` — объект, содержащий метаданные книги (название, автор), её полный текст и технические поля для контроля прогресса пользователя.
